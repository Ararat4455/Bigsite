Form Components

Reusable form components and inputs

Basic Form Elements

Text Input

Standard text input field

<div class="form-group"> <label class="form-label" for="inputId">Label</label> <input type="text" id="inputId" class="form-input" placeholder="Enter text..."> </div>

Textarea

Multi-line text input

<div class="form-group"> <label class="form-label" for="textareaId">Label</label> <textarea id="textareaId" class="form-textarea" placeholder="Enter text..."></textarea> </div>

Select Dropdown

Dropdown select input

<div class="form-group"> <label class="form-label" for="selectId">Label</label> <select id="selectId" class="form-select"> <option value="">Select an option...</option> <option value="option1">Option 1</option> <option value="option2">Option 2</option> </select> </div>

Slider input for selecting a range

Checkbox & Radio

Checkbox

Checkbox input for multiple selections

<div class="form-check"> <input type="checkbox" id="checkboxId" class="form-check-input"> <label class="form-check-label" for="checkboxId">Label</label> </div>

Radio Buttons

Radio input for single selection

<div class="form-check"> <input type="radio" id="radioId" name="radioGroup" class="form-check-input"> <label class="form-check-label" for="radioId">Label</label> </div>

Form Layouts

Form Row

Multiple inputs in a row

<div class="form-row"> <div class="form-group"> <label class="form-label" for="firstName">First Name</label> <input type="text" id="firstName" class="form-input"> </div> <div class="form-group"> <label class="form-label" for="lastName">Last Name</label> <input type="text" id="lastName" class="form-input"> </div> </div>

Inline Form

Form elements in a single line

<div class="form-inline"> <input type="text" class="form-input"> <button class="btn btn-primary">Submit</button> </div>

Form with Icon Inputs

Inputs with icons

<div style="position: relative;"> <input type="text" class="form-input" placeholder="Search..." style="padding-left: 40px;"> <span style="position: absolute; left: 15px; top: 50%; transform: translateY(-50%);"> <i class="fas fa-search"></i> </span> </div>
